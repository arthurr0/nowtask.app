# Documentation images

Screenshots referenced by the README live here. They are produced from a local instance
seeded with sample data, so that no real people, organizations or keys appear.

| File | What it shows |
|---|---|
| `board.png` | The board view with the scrum preset columns, the light theme |
| `list.png` | The list view with grouping and the filter bar |
| `timeline.png` | The timeline view |
| `calendar.png` | The calendar view |
| `task.png` | A task with its subtasks, comments, relations and history |
| `dashboard.png` | The overview dashboard |
| `automations.png` | The rule list and the run log |
| `agents.png` | The AI agents screen with the client setup wizard |
| `board-dark.png` | The board in the dark theme |

Guidelines: capture at 1440 by 900 in the light theme with the graphite accent, except the
dark board, set the interface language to English and the browser timezone to UTC, export as
PNG, and keep each file under 400 KB. The sample organization is "Northwind Studio" with the
project "Website relaunch" and the people Anna Kowalska, Marek Nowak, Julia Schmidt and Tomasz
Wiśniewski.
